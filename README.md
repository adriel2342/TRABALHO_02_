A evolução deste projeto representa um salto significativo tanto na arquitetura de software quanto na infraestrutura de implantação. Inicialmente concebido com uma estrutura procedural simples, o sistema foi reestruturado sob o paradigma da Programação Orientada a Objetos (POO), permitindo modelar com precisão diferentes classes de equipamentos de rede, seus fatores de exposição individuais e o encapsulamento das regras de negócio e persistência de dados. O ciclo de desenvolvimento e entrega ganhou maturidade profissional com a adoção de Docker, Git e SSH. O versionamento com Git garantiu o controle seguro das alterações do código, enquanto a conteinerização via Docker isolou a aplicação e suas dependências em um ambiente portátil com volumes persistentes — possibilitando o deploy remoto via túnel criptografado SSH e a execução contínua do sistema em servidor com alta disponibilidade.
